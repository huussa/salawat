# 🕌 مواقيت الصلاة

A simple web application that displays daily prayer times in a clean and easy-to-use interface.

I originally built this project for my mother to provide a simple way to check prayer times.

## 🌐 Live Demo

[View the website](https://huussa.github.io/salawat/)

## ✨ Features

- Displays daily prayer times.
- Simple and user-friendly interface.
- Responsive design for different screen sizes.
- Lightweight and easy to use.

## 🛠️ Technologies Used

- HTML
- CSS
- JavaScript

## 🚀 Getting Started

To run the project locally:

```bash
git clone https://github.com/huussa/salawat.git
```

Then open the `index.html` file in your browser.
